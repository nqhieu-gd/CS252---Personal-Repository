* Machine learning use data pattern that has been shown to predict the general property of that data.



* Decision tree is one of those models that utilize that process for its prediction.



* The simplest decision tree can be shown as:

    Is A-clause true?

    	+ Yes -> prediction X

    	+ No -> prediction Y



* From data, we can deduct a pattern and use that for our prediction, it is called **fitting** or **training** the model.



* Data used for **fitting** is called **training data.**



* A trained model can be used to predict new data of similar type.



* A decision tree can be added **more splits** to, it is called a **deeper tree** and it offers more precise data property than a simple decision tree.



* The bottom node of the decision tree, at which you arrive and make a prediction for the data, is called a **leaf.**
